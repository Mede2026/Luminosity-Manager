True Tone

Comme sur iPhone : le blanc de l'écran s'adapte à la couleur de la lumière de la pièce. Plus chaud (jaune) sous des lampes, plus froid (bleu) en plein jour. Les couleurs paraissent plus naturelles et c'est plus doux pour les yeux.

Si Sécurité Windows bloque l'app

L'app n'est pas signée (un certificat coûte cher) : Sécurité Windows la prend parfois pour un virus, par erreur. C'est un faux positif.

  • Récupérer l'app : Sécurité Windows → Protection contre les virus et menaces → Historique de protection → clique sur le blocage → Actions → Restaurer. Ou retélécharge-la sur GitHub.
  • Signaler l'erreur à Microsoft : envoie le fichier comme « fichier incorrectement détecté ». C'est corrigé en général en quelques jours.
  • Avant chaque mise à jour, l'app garde une copie de secours. Si la nouvelle version est bloquée, l'ancienne est remise toute seule.
